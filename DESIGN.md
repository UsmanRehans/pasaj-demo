## Overview

Observed source system as of September 21, 2026. The owner pinned the existing website as visual authority. This document records the incumbent system; it is not a redesign. See `docs/brand/README.md` and `docs/visual-audit.md` for reasoning and measurements.

## Colors

White surfaces, black text and outlines, near-white inverse controls. Images carry amber, earth, skin and botanical tones. Source alternate schemes include burgundy and blue-green, but they are not a license to introduce new homepage accent colors.

## Typography

Monospace throughout core storefront copy; the PASAJ logo is an image. Desktop reference sizes above were measured at 1280px. Mobile headings are 21px, body 15.75px; the large newsletter heading shifts from 42px to 31.5px. System fallback font metrics vary by platform.

## Layout

At 1280px, header is about 125px; content width 1155px. Full-bleed hero precedes alternating equal-width photo/text pairs. Collections are four square images across. Mobile header is about 62px; pairs stack image first and collections become one column. Retain section sequence and source crops.

## Elevation & Depth

Core content is flat. Overlays use restrained shadow/backdrop for separation. Do not add decorative depth to product or collection cards.

## Shapes

Core controls have square corners and thin outlines. The original third-party chat/popup surfaces differ; document preview replacements rather than claiming exact service replication.

## Components

Centered wordmark, second-row desktop navigation, compact mobile drawer; restrained buttons; image-led collections; product gallery and expandable details; 16:9 candle carousel; newsletter and footer. Browser-local cart and search use source catalog data. Checkout handoff is explicit.

## Do's and Don'ts

Use original photos and actual product names. Preserve monospace, generous spacing and responsive behavior. Do not add gold, decorative serif typography, invented claims, unverified badges or a new campaign layout. A source-copy replica is not evidence that backend services have been migrated.
