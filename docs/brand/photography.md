# Photography and art direction

The owner explicitly requested the original website photos. The replica captures the source files and their responsive image variants; provenance is recorded in `docs/asset-manifest.json`. No generated replacement imagery is used.

## Observed image vocabulary

Product still lifes combine restrained packaging, amber-toned bottles, pale labels, surfaces and controlled light. Lifestyle images place the work near skin, landscape and tactile materials. Color comes mainly from the image world while interface chrome recedes.

## Cropping rules from the actual layout

Desktop pairs are equal-width photo/text compositions; some alternate sides. On mobile every pair puts the image first. Collection photos become a single column of squares. The candle slideshow retains a 16:9 photo with mobile CTA separated below. The hero uses a different crop at narrow widths.

Use the original responsive `srcset`, object positioning, overlay and aspect behavior. A technically identical image file can still feel wrong if its crop, darkness or placement changes.

## Future photography proposals

If future work calls for new imagery, match packaging truth, material scale, restrained styling and the source’s quality of light. Vita should review references and prompts before image generation and inspect every resulting asset. These are future workflow recommendations, not permission to replace photos in this replica.
